人物文档

                
    
                  
  • 推荐使用 `## 角色名` 作为每个角色的开头。
    • 
                  
  • 也支持“单独一行角色名 + 下一段简介”。
    • 
                  
  • 字段名可写：身份、外貌、性格、固定、禁止变化、道具、关系、别名、代号。
    • 
                  
  • 参考图可写 Markdown 图片，也可上传后在绑定表里选择角色。
    • 
                

                
## 角色名
- 身份：主角 / 指挥官 / 研究员
- 外貌：短发，白外套，红色眼睛
- 固定：发色不能变，始终带工具箱
- 关系：与另一角色是搭档

              

              

                
小说分镜

                
    
                  
  • 章节标题推荐写成 `# 第一章`、`第二章` 或 `Chapter 1`。
    • 
                  
  • 自然段越清楚，场景切分越稳定；长段会按长度自动切块。
    • 
                  
  • 角色名或别名出现在段落里，才会被本地规则识别为当前分镜角色。
    • 
                  
  • 地点、时间、情绪写在段落内，有助于本地 prompt 更准确。
    • 
                

              

              

                
不开 LLM 时

                
    
                  
  • 本地规则会生成角色卡、章节切分、分镜选择、基础 prompt 和连续性提示。
    • 
                  
  • LLM 主要用于复杂人设拆分、场景理解、英文 prompt 精修和外貌状态计划。
    • 
                  
  • 想省 token 时，先按规则整理输入，再关闭 LLM 增强。
