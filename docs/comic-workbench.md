# AI 漫画工作台

漫画工作台位于 `/comic`，主界面顶部可在小说配图和漫画之间切换。两种工程独立保存，共用 API 管理中的 LLM 和图片供应商。漫画规划、生图、Prompt 重建均使用漫画专用策略；不启用全局构图预设。

## 使用

1. 新建工程，粘贴/导入原文；也可选择已有小说工程创建副本。副本复制角色资料、参考图、画风快照与当前插图候选，后续修改不写回小说工程。
2. 编辑角色的固定身份核心、外貌状态及确认标记。旧 identity_prompt 可能包含默认服装，漫画以独立 identity_core 为固定身份；原始身份 Prompt 仍保留在角色资料中。没有可靠资料时手动补充，不自动猜测换装。
3. 填写目标页数、每页格数与节奏要求，选择是否使用语言模型。关闭模型可按原文区间生成可编辑的基础草稿；这是本地切分，不代表模型编剧效果。规划先产生脚本，不调用生图。
4. 左侧使用“工程 / 素材 / 生成”切换面板，历史与导出默认折叠。画布选择“拖框建格”后，在纸面拖出矩形即可新增画格；选择工具下直接拖动画格移动，拖动右下角缩放，松手自动保存。Esc 返回选择工具。也可通过页/格操作和模板调整布局。剧情、角色状态、Prompt、布局可分别锁定。模板只调整未锁定布局，保留图像与对白。新增/拆分/合并/跨页移动均保留稳定 ID 或分配新 ID。
5. 为每格选择角色、状态节点、动作、表情、镜头与场景。状态可作用于当前格或延续后续格，跨页继承。重排和节点修改会重新计算状态并提示检查；状态锁保留原快照并报告变化。不会自动重画。
6. 新增对白、旁白或拟声词，设置说话者、顺序、位置、尾巴、字号、行距及横/竖排。文字数组顺序为阅读顺序。工程默认文字模式可被页、格覆盖。保存后预览更新，修改文字不调用图片接口。
7. 勾选画格生成，或选择缺图/失败项。重生成保留候选图片版本，可手动激活。失败重试使用原请求快照；供应商/模型/选项变化需显式重新生成。角色、画风和场景原图分用途发送，不支持的适配器明确报错。
8. 使用检查工程查看缺失状态、无效绑定、连续性变化与文字溢出；调整字号或气泡大小解决溢出。检查不能证明视觉一致性。
9. 保存、刷新或从工程列表重新打开。脚本/布局历史与图片历史独立，恢复脚本历史不删除图片版本。
10. 导出单页/多页 PNG、PDF、竖向条漫或可重导入工程包。导出可统一覆盖为有字、空白气泡或纯画面。

## 数据与资源

`<数据目录>/outputs/comics/<comic_id>/comic.json` 是漫画的唯一业务数据源；`tasks.json` 为任务执行记录，`assets/` 为工程持有的素材，`exports/` 为可重建导出文件。素材由上传内容散列命名，生成图片使用唯一名称；角色/画风/场景引用及历史使用工程内相对路径。复制来源工程时会实际复制素材，不依赖临时上传目录。普通保存使用 revision 乐观并发控制，冲突返回 409 并保留客户端输入。

数据版本为 `schema_version: 1`。页、画格、角色、状态和文字有稳定 ID。工程包保存 project.json、实际引用素材及 SHA-256 元数据。导入在内存中检查版本、路径、重复文件、符号链接、大小、CRC 与散列，创建新工程，不覆盖已有工程。压缩包上限 256 MiB、总解压 512 MiB、单项 64 MiB、4096 项；大工程可继续本地编辑，便携包超过限制会明确报错。

画布预览与所有成品导出使用相同 Pillow 渲染及 Noto Sans SC 字体度量。字体随应用分发，许可证见 `web/fonts/OFL.txt`，来源见 `web/fonts/SOURCE.txt`。PDF 采用高分辨率栅格页面，文字不可搜索。条漫按 8192 像素高度分段并按顺序打包；元数据记录分段，避免无限长图造成内存耗尽。单页限制 8192 边长和 3200 万像素。单次规划限制 2000 格，可分次扩展，无固定工程页数上限。

## 任务与能力边界

漫画共用现有 TaskManager 与 OpenAICompatibleProvider（包括 ComfyUI）。任务保存在漫画目录，刷新可查看；服务重启后未完成任务明确显示中断，不声称自动续跑。点击“失败画格”重试时，中断画格沿用已持久化请求；不会因编辑后的 Prompt、角色或画风重新组装。已删除画格的图像版本保存在工程内档案中，恢复脚本历史可重新关联。只有点击规划/重建/生图且选择模型时才调用外部服务，没有自动收费测试。

画风预设通过专用选择接口固定快照并复制参考文件；场景节点可保存共用描述和 reference_images。现有独立视觉原图传输用于场景图，发送时标明场景用途，不绑定全局构图预设。ComfyUI/SiliconFlow 当前不支持独立场景/画风原图，会阻止调用并提示使用文字或切换接口。多图云接口的实际用途分离程度由模型决定。

当前矩形分格、程序气泡、裁切和中文横竖排已实现；不包含斜格、破格、局部重绘、姿态控制或整页模型生成。首版提供 Noto Sans SC 常规/粗体选择；其他字体家族尚未开放。对超长文本会报告溢出，用户需要调整文字框/字号；不会悄悄缩字或丢台词。

## 验证

运行 Python 测试：`python -m pytest -q`。前端纯函数/保存队列测试：`node --test tests/frontend/*.js tests/test_storyboard_workspace.js`。漫画测试覆盖跨页换装、重排与锁、原文校验、指定格生成和固定重试快照、三种文字模式、像素渲染、图片裁切、导出与工程包安全。

真实模型效果需要用户配置服务后主动生成验证。模拟供应商测试仅验证请求、状态和版本管理，不代表图像质量或人物视觉一致性。
